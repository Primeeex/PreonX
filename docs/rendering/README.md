# Rendering

This directory contains documentation about the PreonX rendering engine (luminium).

## Planned Contents

- **Overview** — Rendering system architecture
- **Frame Graph** — Render pass management and resource aliasing
- **Materials** — Material system and shader integration
- **Lighting** — Light types, shadow mapping, global illumination
- **Cameras** — Camera types and projection matrices
- **Post-Processing** — Effect pipeline and screen-space techniques
- **Backend** — Graphics API abstraction (Vulkan)
- **Shaders** — Shader compilation and management

## Status

Rendering documentation will be developed in Stage 5.
