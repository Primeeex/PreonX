# Documentation

This directory contains the complete documentation for the PreonX engine ecosystem.

## Structure

| Directory | Content |
|-----------|---------|
| [architecture/](architecture/) | System design, subsystem relationships, data flow |
| [development/](development/) | Build guides, workflows, coding standards |
| [mathematics/](mathematics/) | Mathematical foundations (vectors, matrices, quaternions) |
| [physics/](physics/) | Physics simulation documentation |
| [rendering/](rendering/) | Graphics pipeline and rendering system |
| [ecs/](ecs/) | Entity Component System architecture |
| [assets/](assets/) | Asset pipeline and resource management |
| [audio/](audio/) | Audio system documentation |
| [api/](api/) | Public API reference |
| [examples/](examples/) | Example project documentation |
| [contributing/](contributing/) | Contribution guides and standards |

## Building Documentation

Documentation is maintained as Markdown files. A static site generator (e.g., MkDocs or mdBook) may be configured in a future stage.

## Contributing to Documentation

- Use clear, concise language.
- Include code examples where appropriate.
- Follow the [Markdownlint](https://github.com/DavidAnson/markdownlint) rules defined in `.markdownlint.json`.
- Ensure all links are valid.
