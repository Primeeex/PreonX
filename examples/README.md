# Examples

Example projects demonstrating PreonX engine usage.

## Planned Examples

- **basic/** — Minimal engine setup and window creation
- **physics/** — Rigid body simulation demo
- **rendering/** — Scene rendering with materials and lighting
- **audio/** — Spatial audio playback
- **ecs/** — Entity Component System usage patterns

## Current Status

The `basic/` example contains a placeholder that builds successfully but contains no engine logic. It demonstrates the intended repository layout.
